### 🛡️ [WebAudit-Sec](https://github.com/ZaperMaster/WebAudit-Sec)

Auditor de seguridad web: revisa **cabeceras, cookies, TLS, DNS y archivos expuestos** de una página o de todo un
sitio, y explica cada hallazgo con su evidencia, su recomendación y su referencia **OWASP**. Informes en PDF, HTML,
JSON o CSV, en español o en inglés. Versión web y app de escritorio para Windows.
